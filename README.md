## Core Investigation Workflow

1. Validate the alert.
2. Identify the affected user, host, account or asset.
3. Collect relevant evidence.
4. Determine scope and potential impact.
5. Identify indicators of compromise.
6. Contain when authorized.
7. Escalate when required.
8. Document findings and actions.
9. Close or continue monitoring.
