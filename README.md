# SOC Analyst Lab

A practical blue-team portfolio documenting my preparation and hands-on learning for a SOC Analyst L1 role.

## Focus Areas

- Security monitoring and alert triage
- Incident response
- Phishing and email security investigations
- Network and security fundamentals
- DNS security and common attacks
- IOC identification and enrichment
- Log analysis
- Detection concepts
- Root cause analysis
- Incident documentation

## Lab Structure

### 01 — Home SOC Lab
Practice environment, tools, workflow, and investigation methodology.

### 02 — Email Security & Phishing Investigation
Phishing indicators, header analysis, URLs, attachments, IOCs, containment and escalation.

### 03 — Incident Response & Alert Triage
L1 triage workflow, severity assessment, evidence collection, containment, escalation and closure.

## Investigation Workflow

1. Validate the alert
2. Identify the affected user, host, account or asset
3. Collect relevant evidence
4. Determine scope and potential impact
5. Identify indicators of compromise
6. Contain when authorized
7. Escalate when required
8. Document findings and actions
9. Close or monitor the incident

## Goal

Build practical SOC skills while documenting each investigation clearly enough for another analyst to reproduce the reasoning and understand the response.

> All scenarios in this repository are for learning and defensive security practice.
