# 01 — Home SOC Lab

## Objective

Build a small defensive security lab for practicing SOC Analyst L1 workflows.

## Core Workflow

**Alert → Validate → Investigate → Scope → Contain → Escalate → Document → Close**

## Skills Practiced

- Reading security alerts
- Identifying affected assets
- Working with timestamps
- Investigating IP addresses, domains and hashes
- Reviewing authentication and network activity
- Separating true positives from false positives
- Writing concise incident notes

## Suggested Tools

- Windows Event Viewer
- Linux logs
- Wireshark
- VirusTotal
- CyberChef
- MITRE ATT&CK
- SIEM concepts and sample logs

## Lab Notes

Future exercises will document the alert, evidence, analysis, response and lessons learned.
